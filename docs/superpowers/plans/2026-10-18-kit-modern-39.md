**Goal:** Crear el módulo `src/kit/` (contrato de recetas, estilos por barrio, props, techos, registro `RECIPES` con un test genérico) con la familia `modern` mudada desde `district.ts`, dejar `district.ts` como orquestador fino, sacar las props inline de `city.ts`/`streets.ts`, y publicar `lab/kit.html`.

## Decisiones de implementación (declaradas)

1. **`lot.z` es la superficie donde apoya la receta.** Las recetas no suman `PLINTH_H` por su cuenta: el cuerpo de la torre de vidrio, del clásico y de la obra arranca en `lot.z`. El zócalo de manzana lo pone el llamador. `districtBlock` usa `z: PLINTH_H` para vidrio, clásico y obra (encima del zócalo de `paving` que pone como hoy) y `z: 0` para el campus, que hoy no lleva zócalo de manzana y trae los suyos bajo cada edificio. El issue dice "`z: 0`"; con `z: 0` las recetas tendrían que sumar `PLINTH_H` adentro y el lab (que pone zócalo bajo cada lote) no podría usar el mismo `lot.z` para todas. Las coordenadas absolutas de la ciudad quedan iguales.
2. **Tope de altura de las recetas `modern`.** El contrato pide `max.z ≤ lot.z + 18` (24 si `landmark`) y `≤ lot.z + lot.maxH`; hoy la torre de vidrio llega a `PLINTH_H + 27.2` (24 de cuerpos + losas + terraza) y el clásico a `PLINTH_H + 23.05`. Se resuelve así:
   - `glassTower`, `classic` y `constructionSite` llevan `landmark: true` (son el skyline del distrito, que ya pasaba de 18; el issue marca la obra y la spec §6 dice que el distrito queda "como hoy").
   - Cada receta elige su altura dentro de `min(lot.maxH, 24)` contando sus remates. Clásico: remate 1 + 3·1.35 = 5.05 ⇒ cuerpo ≤ 18, igual que hoy. Vidrio: con el peor reparto en cuerpos (redondeo de `max(3, round(h·share))`, 0.3 de losa por cuerpo y 2.3 de terraza) el cuerpo pedido más alto que entra en 24 es 19 ⇒ `rng.int(16, 19)` en lugar de `rng.int(16, 24)`. Consume el rng igual (una llamada), así la mezcla de la ciudad no cambia; solo bajan las torres más altas (de hasta 27.5 a ≤ 24.3 absolutos). La baliza pasa de `h ≥ 20` a `h ≥ 18` para que siga habiendo.
   - La pluma de la grúa pasa de 14 a 13: con 14 sobresale 1 del lote útil de 21 (regla del 0.8).
3. **`Slot.local`**: índice del local (frente de planta baja) dentro de la pieza. El cartel de `modern` es uno por edificio ⇒ `local: 0`. La hilera de locales (#40) numera sus locales.
4. **`Lot.open` en el distrito**: `[]`. Ninguna receta `modern` lo lee; la zonificación (#44) lo calcula.
5. **Estilo en `modern`**: las recetas conservan sus materiales de firma (`curtain`, `stone`, `office`) y toman del estilo `trim` (losas, cornisas), `roof` (el `gable` del clásico) y `tone` (cuerpos con fachada). Con `STYLES.distrito` (`officeDark`/`copper`/0) la salida es la de hoy; las teclas 1..4 del lab sí cambian cornisas y techos.
6. **Props sin medida "de hoy" única**: la terraza con selva de `roofDetail` (dos conos `leaf` r 1.2 h 2.5) es `roofShrub(at)`; la terraza verde del distrito (losa `leafDark` + 3..5 conos r 1 h 2) es `rooftopGarden(at, w, d, rng)`, y `greenRoof(f, rng)` en `roofs.ts` la apoya sobre una huella. `lamp` devuelve además `bulb` (el malecón usa esa posición para sus neones). `puddle` acepta `z` opcional (0.12 por defecto) para que la fuente ponga el charco sobre el agua de la pileta. `dockCrane` recibe `dir: "e" | "w"` (el muelle oeste mira al agua por el oeste). `garland` toma la z de la polilínea (quien la usa pasa z 3).
7. **El cartel `sign` es el de `tech.ts`** (caja `officeDark` de 0.4 de fondo + poly `amber` 0.02 delante, inset 0.3/0.2), y `tech.ts` pasa a usar el del kit: "la única implementación" (issue). El campus pierde el halo `amberBleed` y gana la caja; en `tech` los carteles quedan idénticos.
8. **`tech.ts` usa el kit** porque `lamp` y `campus` salen de `city-pieces.ts` (lo pide el issue): `lamp` del kit y la receta `campus` con `z: 0` y `STYLES.distrito`. Su campus pierde las baldosas verdes de la vereda (1.5 alrededor): las baldosas de la receta cubren el lote, no la manzana.
9. **Cornisa de `city.ts`** (`building`) pasa a `roofs.cornice` y la regla del retranqueo a `roofs.stepTop`: "un solo lugar para la regla". Misma geometría.
10. **Helpers del kit en `src/kit/piece.ts`**: `emptyPiece()`, `addBuilding(p, solid, facade)` (empuja el sólido y publica sus paredes y ventanas que miran a la cámara) y las constantes `RECIPE_MAX_H = 18`, `LANDMARK_MAX_H = 24`. Las usan todas las familias.
11. **La escena del lab es pura** (`src/lab/kit-scene.ts`, testeable sin Pixi); `src/lab/kit.ts` solo hace `Application`, capas y teclas, con sombras bajo `AlphaFilter` y acentos en `blendMode: "add"` como `src/world/stage.ts`.

import { v3 } from "../iso/geometry";
import { STEP_INSET, type Solid } from "../iso/solids";
import type { Material } from "../map/palette-iso";
import type { Rng } from "../map/seed";
import { prism } from "../scenes/city-pieces";
import { rooftopGarden } from "./props";

/**
 * Techos del kit. Todos reciben la huella de apoyo (`z` = techo del cuerpo) y
 * devuelven sólidos. Regla: sobre un techo escalonado lo que va encima apoya
 * en la huella retranqueada (`stepTop`), no en la del cuerpo, o flotaría
 * sobre el retranqueo.
 */
export interface Footprint { x: number; y: number; w: number; d: number; z: number }

export const cornice = (f: Footprint, mat: Material): Solid[] => [prism(f.x - 0.5, f.y - 0.5, f.z, f.w + 1, f.d + 1, 0.4, mat)];

/** Huella del segundo nivel de un techo escalonado de alto `h` (el mismo retranqueo que `roof: "step"`). */
export function stepTop(f: Footprint, h: number): Footprint {
  const ix = f.w * STEP_INSET, iy = f.d * STEP_INSET;
  return { x: f.x + ix, y: f.y + iy, w: f.w - 2 * ix, d: f.d - 2 * iy, z: f.z + h };
}

export function stepRoof(f: Footprint, h: number, mat: Material): Solid[] {
  const t = stepTop(f, h);
  return [prism(t.x, t.y, f.z, t.w, t.d, h, mat)];
}

export const gableRoof = (f: Footprint, h: number, mat: Material): Solid[] => [prism(f.x, f.y, f.z, f.w, f.d, h, mat, { roof: "gable" })];

/** Para cada poly cóncavo, ningún otro sólido de la pieza tiene parte de su caja en el hueco (casco convexo menos huella). */
function concaveIntruders(solids: Solid[]): number {

import { facadeWindows, type Facade } from "../iso/facade";
import { visibleWalls, type Solid } from "../iso/solids";
import type { Piece } from "./types";

/** Tope de altura sobre `lot.z` de una receta común y de una `landmark`. */
export const RECIPE_MAX_H = 18;
export const LANDMARK_MAX_H = 24;

export const emptyPiece = (): Piece => ({ solids: [], ground: [], accents: [], windows: [], slots: [], walls: [] });

/** Suma un edificio con fachada `f` y publica sus paredes y ventanas que miran a la cámara (normal con x > 0 o y > 0). */
export function addBuilding(p: Piece, s: Solid, f: Facade): void {
  const building = p.solids.push(s) - 1;
  for (const w of visibleWalls(s)) {
    if (w.normal.x <= 1e-9 && w.normal.y <= 1e-9) continue;
    p.walls.push({ pts: w.pts, normal: w.normal, floorH: (w.pts[2]!.z - w.pts[0]!.z) / f.floors, building });
    for (const win of facadeWindows(w, f)) p.windows.push({ ...win, wall: w.normal, building });
  }
}

export const SIGN_MIN_H = 12;
export const MAX_CLASSIC_H = 18;
const CURTAIN_WINDOW = { w: 0.85, h: 0.8 } as const;

/** Hueco del cartel de neón en la cara sur, a media altura: 1.6 de alto, 1 de margen a cada lado, 0.4 delante de la pared. */
function southSign(x: number, southY: number, w: number, z0: number): Slot {
  const y = southY + 0.4, z1 = z0 + 1.6;
  return { pts: [v3(x + 1, y, z0), v3(x + w - 1, y, z0), v3(x + w - 1, y, z1), v3(x + 1, y, z1)], wall: v3(0, 1, 0), side: "s", kind: "sign", local: 0 };

const tierHeights = (h: number, tiers: number): number[] => (tiers === 3 ? [0.6, 0.3, 0.1] : [0.7, 0.3]).map((s) => Math.max(3, Math.round(h * s)));
const GLASS_CROWN = 2.3; // terraza verde: losa 0.3 + cono 2 (el helipuerto es más bajo)

/** Altura pedida más alta que entra en `cap` con el peor reparto en cuerpos (2 o 3, cada uno con su losa de 0.3) y la terraza. */
function glassMaxH(cap: number): number {
  let h = Math.floor(cap);
  while (h > 3 && [2, 3].some((t) => tierHeights(h, t).reduce((a, b) => a + b, 0) + 0.3 * t + GLASS_CROWN > cap)) h--;
  return h;
}

export function glassTower(lot: Lot, rng: Rng, style: Style): Piece {
  const p = emptyPiece(), { x, y, w, d } = lot;
  const hMax = glassMaxH(Math.min(lot.maxH, LANDMARK_MAX_H));
  const h = hMax < 16 ? hMax : rng.int(16, hMax);
  const bw = rng.int(12, 14), bd = rng.int(10, 12);
  const bx = x + (w - bw) / 2, by = y + (d - bd) / 2;
  const tiers = rng.int(2, 3);
  const insets = [0, 2, 4];
  let z = lot.z;
  tierHeights(h, tiers).forEach((th, t) => {
    const ins = insets[t]!, tw = bw - 2 * ins, td = bd - 2 * ins;
    const facade: Facade = { floors: Math.max(1, Math.round(th / 3)), cols: Math.max(2, Math.round(tw / 2.5)), window: CURTAIN_WINDOW, ...(t === 0 ? { base: "glass" as const } : {}) };
    addBuilding(p, prism(bx + ins, by + ins, z, tw, td, th, "curtain", { facade, tone: style.tone }), facade);
    p.solids.push(prism(bx + ins - 0.3, by + ins - 0.3, z + th, tw + 0.6, td + 0.6, 0.3, style.trim)); // losa de remate de cada cuerpo
    z += th + 0.3;
  });
  const ins = insets[tiers - 1]!, cx = bx + bw / 2, cy = by + bd / 2;
  if (rng.chance(0.5)) { const hp = helipad(v3(cx, cy, z)); p.solids.push(...hp.solids); p.accents.push(...hp.accents); }
  else p.solids.push(...greenRoof({ x: bx + ins, y: by + ins, w: bw - 2 * ins, d: bd - 2 * ins, z }, rng));
  if (h >= 18) p.accents.push(...beacon(v3(bx + bw - ins, by + ins, z + 0.5)).accents);
  if (h >= SIGN_MIN_H) p.slots.push(southSign(bx, by + bd, bw, lot.z + h / 2 - 0.8));
  p.landmarkTop = v3(cx, cy, z);
  return p;
}

const CLASSIC_CROWN = 1 + 3 * (1 + GABLE_RATIO); // cornisa pesada + gable de 3, el más alto de los dos remates

export function classic(lot: Lot, rng: Rng, style: Style): Piece {
  const p = emptyPiece(), { x, y, w, d } = lot;
  const hMax = Math.min(MAX_CLASSIC_H, Math.floor(Math.min(lot.maxH, LANDMARK_MAX_H) - CLASSIC_CROWN));
  const h = hMax < 12 ? hMax : rng.int(12, hMax);
  const bw = rng.int(14, 17), bd = rng.int(11, 13);
  const bx = x + (w - bw) / 2, by = y + (d - bd) / 2;
  const floors = Math.max(2, Math.round(h / 3.5)), cols = rng.int(4, 5), fh = h / floors;
  const facade: Facade = { floors, cols, base: "portico" };
  addBuilding(p, prism(bx, by, lot.z, bw, bd, h, "stone", { facade, tone: style.tone }), facade);
  for (let k = 0; k <= cols; k++) { // pilastras de planta baja en las caras visibles (este y sur)
    p.solids.push(prism(bx + bw, by + (bd * k) / cols - 0.2, lot.z, 0.4, 0.4, fh, "stone"));
    p.solids.push(prism(bx + (bw * k) / cols - 0.2, by + bd, lot.z, 0.4, 0.4, fh, "stone"));
  }
  const top = lot.z + h;
  p.solids.push(prism(bx - 0.8, by - 0.8, top, bw + 1.6, bd + 1.6, 1, style.trim)); // cornisa pesada
  if (rng.chance(0.5)) p.solids.push(...gableRoof({ x: bx + 2, y: by + 2, w: bw - 4, d: bd - 4, z: top + 1 }, 3, style.roof));

    lots.push({ x, y, name: def.name });
  }
  return { solids: [...ground, ...solids], accents, lots };
}

import { AlphaFilter, Application, Container, Graphics } from "pixi.js";
import { SHADOW_BAND_ALPHA, buildRenderList, type Layer, type RenderItem } from "../iso/render-list";
import { ISO_COLORS } from "../map/palette-iso";
import type { StyleId } from "../kit/types";
import { drawAccents, drawLayer, fitTransform } from "../world/frame";
import { kitScene } from "./kit-scene";

/**
 * Lab del kit: todas las recetas del registro sobre una grilla de lotes. Tecla
 * `s` cambia el seed; `1..4` el estilo (centro, bares, residencial, cívico).
 * Sin bloom ni animadores.
 */
const KEY_STYLE: Record<string, StyleId> = { "1": "centro", "2": "bares", "3": "residencial", "4": "civico" };
const LAYERS: readonly Layer[] = ["ground", "shadow", "shadowCore", "solid"];

const host = document.getElementById("lab-host") as HTMLDivElement;
let seed = 7, style: StyleId = "centro";
void boot();

async function boot(): Promise<void> {
  const app = new Application();
  await app.init({ resizeTo: host, background: ISO_COLORS.sky, antialias: true, resolution: window.devicePixelRatio || 1, autoDensity: true });
  host.appendChild(app.canvas);
  const world = new Container(), layers = LAYERS.map(() => new Graphics()), lights = new Graphics();
  for (const [i, l] of LAYERS.entries()) if (l === "shadow" || l === "shadowCore") layers[i]!.filters = [new AlphaFilter({ alpha: SHADOW_BAND_ALPHA })]; // cada banda como unión, igual que stage.ts
  lights.blendMode = "add";
  world.addChild(...layers, lights);
  app.stage.addChild(world);
  let items: RenderItem[] = [];
  const fit = (): void => { const f = fitTransform(items, host.clientWidth, host.clientHeight); world.position.set(f.x, f.y); world.scale.set(f.scale); };
  const draw = (): void => {
    const s = kitScene(seed, style);
    items = buildRenderList(s.solids);
    LAYERS.forEach((l, i) => drawLayer(layers[i]!, items, l));
    drawAccents(lights, s.accents);
    fit();
  };
  draw();
  app.renderer.on("resize", fit);
  window.addEventListener("keydown", (e) => {
    const next = KEY_STYLE[e.key];
    if (next) { style = next; draw(); }
    if (e.key === "s") { seed++; draw(); }
  });
}
