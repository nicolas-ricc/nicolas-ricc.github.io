# Nave de calderas a 9 vanos (#243) — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use `subagent-driven-development` (`.agents/skills/subagent-driven-development/SKILL.md`) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Acortar la nave de calderas de 11 a 9 vanos de 7 u (w 76 → 63), en su lugar de hoy (x 44), derivando de `BAYS`/`BAY` todas las cuentas que dependen del largo: pilastras, fachadas, zócalo y tubos, celosía, chimeneas metálicas, cortes del faldón norte, caperuzas, testero, torre de escalera, `PLANT` y portón.

**Architecture:** Solo cambia geometría de escena. `boiler-house.ts` exporta `BAYS`, `BAY`, `NAVE` (con `w = BAYS·BAY`) y deriva todo de ahí con `E = NAVE.x + NAVE.w`. `factory.ts` deriva `PLANT` de `MALT` y `NAVE`. El exhibit `planta` ya usa `STAIR_TOWER.x1` y se acomoda solo; cambia el comentario. Los tests se re-expresan con las constantes (stage de evals) y fijan los valores del issue.

**Tech Stack:** TypeScript estricto, Vitest. Sin dependencias nuevas.

**Spec:** issue #243 ("Qué hacer", "Reglas que hereda", criterios); contexto en `docs/superpowers/specs/2026-10-27-fabrica-mudanza-design.md` §3.2 y el comentario de plan de #238 (decisión 2). Detalle arquitectónico: `docs/superpowers/specs/2026-10-24-fabrica-detalle-design.md` §5 (no cambia).

- Rama base `feature/238-fabrica-mudanza`; el PR va contra esa rama.
- `BAYS = 9`, `BAY = 7`, `NAVE = { x: 44, y: -46, w: BAYS * BAY, d: 30, h: 14 }` (w 63), `E = NAVE.x + NAVE.w` (107).
- Valores finales: `STAIR_TOWER = { x0: 108, y0: -34, x1: 113, y1: -26 }`, `METAL_STACK_X = [51, 65, 79, 93]`, `PLANT.w = 87`, portón x 106.8..107.3, y −23..−17, z 0..8.
- Nada se traslada: `NAVE.x` sigue en 44, `MALT` no cambia, `inclineBelt` no cambia, `STACKS` (pedestal desde x 126.5) no cambia.
