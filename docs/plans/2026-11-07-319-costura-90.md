# Costura en y 90 (#56 · 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the Portfolio/Resume seam from `y 146` to `y 90`, keep the
terminal station in Portfolio through a geographic exception (`STATION_LAND`),
anchor the estuary at `y 146`, cut everything Portfolio had south of 90, raise
a fence along the seam, hand the west main line to Resume as an empty asphalt
strip crossed by the track, and bring the story spec and an ADR into the repo.

**Architecture:** `src/map/geo.ts` gains `ESTUARY_Y0`, `STATION_LAND` and
`inStationLand`; `worldZoneAt`, `terrainAt` and `zoneFrame` use them, so the
veil, the hit test, the terrain and the lab framings follow on their own.
Scenes are cut by hand (shipyard, factory, excavator, hinterland, tech, city
fixed pieces and streets) and a new pure module `src/city/rail-lands.ts` draws
the main line from `WORLD.x0` to the station.

**Tech Stack:** TypeScript (strict, `noUnusedLocals`), Vitest, Vite, PixiJS v8
(only in `src/world` / `src/lab`; `src/iso` and `src/scenes` are Pixi-free).

**Spec:** issue #319 (body copied to `.scratch/issue-319.md` for agents; it is
the source of every number below), under the story spec
`docs/superpowers/specs/2026-10-15-costura-90-portfolio-denso-galpones-feria-design.md`
(Task 1 brings it into the repo). Where they disagree, the issue wins.

## Global Constraints

- Code, identifiers, comments, test names and commit messages in English (`src/english.test.ts`); docs in `docs/` in Spanish; ADRs in English like `0001`.
- `src/iso/` and `src/scenes/` never import Pixi (`src/iso/pixi-free.test.ts`).
- No hex color literals outside `palette-iso.ts`, `palette-base.ts`, `seed.ts`; colors are palette names (`"steel"`, `"cyan"`, …).
- No `Math.random`: all randomness from the `Rng` passed in. When a draw count is kept "the same", keep the same number of rng calls.
- No new dependencies.
- Static solids never in front of the west train: south of the track `y_min − 1.4·z_max ≥ 134.5`, north `y_max ≤ 130.8` (`station.ts` docstring, `train-occlusion.test.ts`).
- Budget caps (`city-budget.test.ts`) become exactly: world static polygons ≤ 56 000; Resume raised solids ≤ 2 900, `strip` ≤ 190, static accents ≤ 1 150. No other cap is raised.
- `world-baseline.test.ts` keeps only `PIECES` and its `it`; the piece hashes must not move.
- Commits: `feat(#319): …`, `test(#319): …`, `docs(#319): …`, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Gates: `npm test` and `npm run typecheck`.

## Review Focus

1. **The quay wall at `x 198..202` runs `y −60..142`**, so it and its bollards break the literal Portfolio rule (`max.x ≤ 198.5`). It is the bank of the station land: the rule test accepts solids with `min.x ≥ 95.5 && max.x ≤ QUAY_X + QUAY_W + 0.5` (station land plus its quay wall). Test in Task 4.
2. **Hinterland sheds exactly on the new seam.** The second west shed row (`y 76`, `d 14`) ends at `y 90`, where `builtAt` is now `urban`, so `onIndustrial` would silently drop it. Move it to `y 75` (edge 89). Test in Task 6: two 36×14 gable sheds at `x −190`.
3. **West-line sleepers in the bleed** (`hinterland.westRails`, `y 130..135`) are in Resume ground (`worldZoneAt` → `cv`). Like the train, they stay with the hinterland. The hinterland "falls in Portfolio" assertion skips the `rust` 1×5×0.3 sleepers. Test in Task 6.
4. **Clicking and veiling the station strip `x 96..100`** reads as Resume street but is Portfolio. `worldZoneAt(98, 120)` is `portfolio`, and its veil cell goes with Portfolio. Test in Task 2 (geo) and Task 5 (`veil.test`: the 6 u cell centred at (99, 117) is portfolio).
5. **Lab framings.** Key `1` must include the whole station (`y1 146`) and key `2` must start at `y 90`. Test in Task 5 (`frame.test`).
