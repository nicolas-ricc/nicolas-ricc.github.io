# Functional lights to `spot()`, sparks and trolley lamp out, 0-dot gate (#403): Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every functional light seen in the 11 storybook exhibits becomes a small haloless `poly` built by a new `spot()` helper, the shipyard animator loses its trolley lamp and welding sparks, and a gate test proves the 11 exhibits draw zero `dot` accents while the rest of the world keeps its dots.

**Architecture:** `spot(at, r, color, alpha = 1)` in `src/iso/accent.ts` returns a 4-point `poly` that projects to a screen rhombus of radius `r` around `project(at)`; `drawAccents` only halos `dot`s, so the spot has none. Each site swaps its `{ kind: "dot", at, r, color }` for `spot(at, r, color)` 1:1 (same position, radius, color, same animation logic). A test-only fixture `spotOf(a)` (same convention as `src/scenes/lamp-fixtures.ts`) recovers `{ at, r, color }` from a spot poly so scene tests keep asserting exact positions. The gate `src/lab/no-dots.test.ts` rebuilds each exhibit the way `src/lab/storybook.ts:79-90` does.

**Tech Stack:** TypeScript, vitest, Pixi-free scene builders.

**Spec:** issue #403 ("Qué existe hoy", "Decisiones heredadas" 1–5, "Criterios de aceptación"), parent story #395, `docs/superpowers/specs/2026-11-16-storybook-luces-y-encuadre-design.md` §1 and criteria 1–3. Base branch `feature/395-storybook-luces-encuadre` (with #401 and #402 merged).

## Global Constraints

- `src/` in **English** (`src/english.test.ts`): code, comments, test names.
- Engine and scene tests stay Pixi-free (`src/iso/pixi-free.test.ts`).
- `spot(at: Vec3, r: number, color: AccentColor, alpha = 1): Accent` with points, in this order: `v3(x + r/2, y − r/2, z)`, `v3(x, y, z + r/Z_SCALE)`, `v3(x − r/2, y + r/2, z)`, `v3(x, y, z − r/Z_SCALE)` (inherited decision 1).
- 1:1 replacements, same `r` and color (inherited decision 2): buffers `0.35 magenta`; signals `SIGNAL_R_DOT` (`in` and `out`, red `magenta` / clear `cyanMid`); crossing `CROSSING_R_DOT magenta` (north and south); train headlights `0.3 cyan`, red lights `0.25 magenta`; lighthouse gallery `GALLERY_R_DOT magenta` (`chase` unchanged); wreck buoy `1 magentaMid`; tinker marquee bulbs `BULB amberMid`, static and the animated one (blink unchanged).
- Stay dots: lighthouse coast lights (`coast`, cyan pulsing), shoal buoys (`buoys()` in `sea-anim.ts`), every lamp from `lamp()`/`industrialLamp()`. `lamp()`/`industrialLamp()` (`src/kit/props.ts`) do not change.
- Shipyard animator: `trolleyLamp`, the sparks (`sparks()`, `burst`, `sparkRng`, `SPARK_GAP_MS`, `SPARK_FRAME_MS`, `SPARK_FRAMES`, `SEED_MAX`, `fired`) and `weldSpots` (in `Scene`, `slipways`, `floatingDock`, `shipyardEast`) go. The trolley `solid` layer stays (inherited decision 3).
- Gate ids, verbatim: `["playa-camiones", "gradas", "estacion", "patio-contenedores", "grua-muelle", "cartel-taller-escena", "silos", "playa-contenedores", "autitos-chocadores", "faro", "pecio"]`; world from `assembleWorld(undefined, { reducedMotion: false })`; 32 frames across 8 s (`BEAM_PERIOD_MS`); zero `kind: "dot"`, no exceptions (inherited decision 4).
- Tests are rewritten to the new state, never deleted to make them pass. `npm test` and `npm run typecheck` (`noUnusedLocals`/`noUnusedParameters`) pass at every task commit.

## Decisions (technical assumptions, declared)

1. **`spotOf` test fixture.** `src/iso/spot-fixtures.ts` exports `spotOf(a: Accent): { at: Vec3; r: number; color: AccentColor; alpha: number } | null`: non-null only for a `poly` with exactly 4 points matching the `spot` pattern within 1e-9 (`at` = `(pts[1].x, pts[1].y, (pts[1].z + pts[3].z) / 2)`, `r = 2 · (pts[0].x − at.x)`, `r > 0`). Used by the scene tests and the gate. Not imported by production code.
2. **Shipyard animator signature.** With the sparks gone `rng` is unused: `createShipyardAnim(scene, opts)` and `shipyardAnimator(scene, opts)`; `src/world/assemble.ts:25` drops `createRng(SEED + 1)` (and the `createRng` import if unused). `ShipyardAnim` becomes `{ tick(dtMs): AnimChanges }` with `AnimChanges = { trolley: boolean }`. Layers: `["trolley"]` only.
3. **`spark` palette color stays.** `ISO_COLORS.spark` and `ACCENT_COLORS` keep it (`palette-iso.test.ts` pins the list; removing a palette entry is outside this issue). Its comment becomes `// welding sparks; no emitter since #403`. `portfolio-accents.test.ts` rule 3 (no static spark) stays; rule 5 ("the shipyard.sparks layer only emits spark") is rewritten to "rule 5: the shipyard animator has no accent layer (#403)".
4. **Veil zone of a spot.** `accentZone` reads `pts[0]` of a poly = `at + (r/2, −r/2, 0)`, at most 0.5 u off. Kept as is; the gate file adds a test that every spot among the world's static accents and the gate's animated frames has `accentZone(a) === worldZoneAt(spotOf(a).at)`.
5. **Exhibit `h`.** `src/lab/exhibits.test.ts` measures `accents` with `HALO_K` for dots only; losing halos can only lower it. If a `framing` test fails because `h` now exceeds measured + `SLACK` 8, lower that exhibit's `h` in `src/lab/exhibits.ts` to measured + ≤ 8 and update its comment (issue: "si algún `h` queda por encima de `SLACK` 8 al perder halos, bajalo con su comentario").
6. **Docs.** `CONTEXT.md` (Accent entry), README and the spec status belong to the story's closing child #405; this plan does not touch them.

## Review Focus

1. A site replaced with the wrong frame or order of points (e.g. `spot` points not centered on `project(at)`): every rewritten scene test asserts `spotOf(a)` deep-equals the old dot's `{ at, r, color }`.
2. Animated logic regressions while swapping (gallery `chase`, crossing alternation every `BLINK_MS`, signal aspects, train lead switch every 4 s, tinker bulb blink): the existing behavioural tests are adapted to `spotOf`, not deleted.
3. Over-replacement: coast lights, shoal buoys or lamp bulbs becoming polys; the gate's second test asserts `calle-faroles` and `boyas` still have ≥ 1 dot, and `sea-anim.test.ts` keeps the coast assertions as dots.
4. Veil drift at a zone border (Decision 4): covered by the gate's zone test.
5. Leftover spark plumbing (`weldSpots` fields, the `rng` parameter, `fired`) surviving because tests still reference them: typecheck with `noUnusedLocals` and `grep -rn "weldSpots\|sparks\|trolleyLamp" src` must find nothing but the palette comment.
