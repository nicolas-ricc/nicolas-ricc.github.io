**Goal:** que `SEED = 7` se defina en `src/map/seed.ts`, junto a `createRng`, y que los módulos que solo necesitan la semilla la importen de ahí y no del ensamblador del mundo.

**Architecture:** mover una constante. `src/map/seed.ts` exporta `SEED`; `src/world/assemble.ts` la importa de ahí y deja de definirla; `src/lab/exhibits.ts`, `src/scenes/city.test.ts` y `src/scenes/fair.test.ts` cambian su import. **Tech Stack:** TypeScript, Vitest.

**Spec:** issue #105 y su Agent Brief (comentario de triage).

## Decisiones técnicas (declaradas)

1. **Sin reexport.** La issue admite reexportar desde `assemble.ts` "o actualizar los importadores". Se actualizan los importadores y `assemble.ts` no reexporta: después del cambio nadie importaría `SEED` de ahí, y un reexport sin consumidores sería una segunda vía para el mismo dato.
2. **Baseline de polígonos.** El criterio "los baselines de polígonos no cambian" se fija con una huella: cantidad de ítems de `buildRenderList` más un FNV‑1a de `[layer, color, pts redondeados a milésimas]`. Se aplica al mundo entero (`assembleWorld`, `ground` + `solids`) y a las dos piezas que usan `createRng(SEED)` (campus y selva). Los valores se tomaron en `main` antes del cambio.
3. **Chequeo de imports por texto.** Que un archivo importe de `map/seed` y no de `world/assemble` se verifica leyendo el fuente con `readFileSync`, el mismo patrón que `src/lab/docs.test.ts`. El typecheck no lo distingue.

## Review Focus

1. Un import combinado (`import { createRng, SEED } from "../map/seed"`) tiene que pasar el chequeo, no solo `import { SEED } …` aislado: la regex acepta cualquier lista que contenga `SEED`.
2. Si `assemble.ts` conserva su propia `const SEED = 7` además de importar, habría dos definiciones que pueden divergir: el test exige que `assemble.ts` no la declare.
3. Si al mover la constante cambia el orden de consumo del Rng en alguna pieza, la escena cambia sin que falle ningún test existente: lo cubren las huellas.
4. La huella debe ser estable entre corridas y máquinas: los `pts` se redondean a milésimas antes de hashear.
5. `fair.test.ts` no está en la issue pero sí en el brief: el chequeo de imports lo incluye.

```ts
import { describe, expect, it } from "vitest";
import type { Accent } from "../iso/accent";
import { buildRenderList } from "../iso/render-list";
import type { Solid } from "../iso/solids";
import { EXHIBITS } from "../lab/exhibits";
import { assembleWorld } from "./assemble";

/** Cantidad de ítems y FNV-1a de capa, color y puntos (a milésimas) de la lista de render. */
function fingerprint(solids: Solid[]): string {
  const list = buildRenderList(solids);
  const text = JSON.stringify(list.map((i) => [i.layer, i.color, i.pts.map((v) => Math.round(v * 1000))]));
  let h = 0x811c9dc5;
  for (let k = 0; k < text.length; k++) h = Math.imul(h ^ text.charCodeAt(k), 16777619) >>> 0;
  return `${list.length}:${h.toString(16)}`;
}

function piece(id: string): Solid[] {
  const e = EXHIBITS.find((x) => x.id === id);
  if (e?.kind !== "piece") throw new Error(`sin pieza ${id}`);
  const out: Solid[] = [], accents: Accent[] = [];
  e.build(out, accents);
  return out;
}

// medidas en main (e2fe6b6), antes de mover SEED a map/seed (#105)
describe("baseline de polígonos con la semilla del mundo", () => {
  it("el mundo entero", () => {
    const { scene } = assembleWorld(undefined, { reducedMotion: true });
    expect(fingerprint([...scene.ground, ...scene.solids])).toBe("25535:d94af20a");
  });
  it.each([["campus", "181:bf94ae67"], ["selva", "73:d107b580"]])("la pieza %s", (id, fp) => {
    expect(fingerprint(piece(id))).toBe(fp);
  });
});
```
