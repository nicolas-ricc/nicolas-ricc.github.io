## Decisiones técnicas (declaradas)

1. **Sin reexport.** La issue admite reexportar desde `assemble.ts` "o actualizar los importadores". Se actualizan los importadores y `assemble.ts` no reexporta: después del cambio nadie importaría `SEED` de ahí, y un reexport sin consumidores sería una segunda vía para el mismo dato.
2. **Baseline de polígonos.** El criterio "los baselines de polígonos no cambian" se comprueba con una huella: cantidad de ítems de `buildRenderList` más un FNV‑1a de `[layer, color, pts redondeados a milésimas]` y los acentos. Se aplica al mundo entero (`assembleWorld`, `ground` + `solids` + `accents`) y a las dos piezas que usan `createRng(SEED)` (campus y selva). Es un script en `.scratch/`, no un test versionado: un hash del mundo entero en la suite fallaría con cada cambio intencional de escena de issues futuras.
3. **Chequeo de imports por texto.** Que un archivo importe de `map/seed` y no de `world/assemble` se verifica leyendo el fuente con `readFileSync`, el mismo patrón que `src/lab/docs.test.ts`. El typecheck no lo distingue.

## Assumptions

1. **La guarda de polígonos no queda en la suite.** Alternativa rechazada: un test versionado con el hash; ataría cada cambio de escena futuro a re-medir un hash opaco, y la issue solo pide que este cambio no altere los polígonos.
2. **El Rng de los animadores no entra en la huella.** `assemble.ts` sigue llamando `createRng(SEED + n)` con el mismo `SEED`; solo cambia de dónde se importa, y eso lo cubre el typecheck más `src/world/assemble.test.ts`. Alternativa rechazada: hashear las capas animadas.
3. **Las regex de import asumen comillas dobles y punto y coma.** No hay formateador configurado (no hay `.prettierrc`, `.editorconfig` ni eslint). Es el estilo de todos los imports del repo (por ejemplo, `src/lab/exhibits.ts:1-19`).

## Review Focus

1. Un import combinado (`import { createRng, SEED } from "../map/seed"`) tiene que pasar el chequeo, no solo `import { SEED } …` aislado: la regex acepta cualquier lista que contenga `SEED`.
2. Si `assemble.ts` conserva su propia `const SEED = 7` además de importar, habría dos definiciones que pueden divergir: el test exige que `assemble.ts` no la declare.
3. Si al mover la constante cambia el orden de consumo del Rng en alguna pieza, la escena cambia sin que falle ningún test existente: lo cubre el script de huellas, acentos incluidos.
4. La huella debe ser estable entre corridas: se midió dos veces en `main` con el mismo resultado; antes y después corre en la misma máquina.
5. `fair.test.ts` no está en la issue pero sí en el brief: el chequeo de imports lo incluye.

```ts
import { buildRenderList } from "../src/iso/render-list";
import type { Solid } from "../src/iso/solids";
import { EXHIBITS } from "../src/lab/exhibits";
import { assembleWorld } from "../src/world/assemble";

// medidas en main (e2fe6b6), Node 22.18.0, antes de mover SEED a map/seed (#105)
const EXPECTED: Record<string, string> = { world: "25535:f190adef", campus: "181:e18c52cd", selva: "73:58be0412" };

/** Cantidad de ítems de render y FNV-1a de capa, color y puntos (a milésimas), más los acentos. */
function fingerprint(solids: Solid[], accents: Accent[]): string {
  const list = buildRenderList(solids);
  const text = JSON.stringify([list.map((i) => [i.layer, i.color, i.pts.map((v) => Math.round(v * 1000))]), accents]);
  let h = 0x811c9dc5;
  for (let k = 0; k < text.length; k++) h = Math.imul(h ^ text.charCodeAt(k), 16777619) >>> 0;
  return `${list.length}:${h.toString(16)}`;
}

const got: Record<string, string> = {};
const { scene } = assembleWorld(undefined, { reducedMotion: true });
got.world = fingerprint([...scene.ground, ...scene.solids], scene.accents);
for (const id of ["campus", "selva"]) {
  const e = EXHIBITS.find((x) => x.id === id);
  if (e?.kind !== "piece") throw new Error(`sin pieza ${id}`);
  const out: Solid[] = [], accents: Accent[] = [];
  e.build(out, accents);
  got[id] = fingerprint(out, accents);
}
const bad = Object.keys(EXPECTED).filter((k) => got[k] !== EXPECTED[k]);
console.log(JSON.stringify(got));
if (bad.length) { console.error(`cambió: ${bad.join(", ")}`); process.exit(1); }
```
