## Decisiones técnicas (declaradas)

1. **Línea de base.** `CLAUDE.md:4` pasa a decir que el sitio se sirve en la raíz `/` (`vite.config.ts`) y que las páginas del lab están en `/lab/<página>.html`. Así lo dice el brief en "Desired behavior".
2. **Enlace al método.** Es un enlace Markdown relativo a `docs/superpowers/specs/2026-10-17-barcos-inventario.md#método-del-time-lapse`. GitHub arma el ancla a partir del encabezado: pasa todo a minúsculas, conserva la tilde y cambia los espacios por `-`. El test comprueba dos cosas: que el archivo existe y que contiene ese encabezado.
3. **Ubicación de la advertencia.** Va en un párrafo propio dentro de la sección de PixiJS DevTools, justo después del bloque que abre `world.html`, porque es ahí donde un agente arma la URL con `?speed=`.
4. **Comentario de `config.toml`.** Pasa a decir: "The site is served at the root (base "/" in vite.config.ts): open http://localhost:5173/; lab pages are at http://localhost:5173/lab/<page>.html." Sigue en inglés porque el archivo ya está en inglés.
5. **Criterio 2 ("funcionan contra `npm run dev`").** Lo comprueba el script de agent-browser y no un test unitario, porque necesita el dev server y un navegador.

## Review Focus

1. Una URL como `localhost:5173/map` sin la barra final no debe sobrevivir en ninguna parte de `.factory/`. El test recorre todos los archivos de `.factory/` y no solo `config.toml`.
2. Un enlace al método con el ancla mal escrita no rompe nada: GitHub abre el archivo sin saltar a la sección. El test exige el ancla exacta y que el encabezado exista en el archivo enlazado.
3. La advertencia tiene que dar números concretos (2 fps, 100 ms, 0,2·N) para que el agente no tenga que deducirlos. El test exige los tres.
4. Si `CLAUDE.md` pierde la línea de base al reescribirla, el test lo detecta: exige `/lab/` y la mención de `vite.config.ts`.
5. El ejemplo tiene que abrir el lab y no el sitio. Lo comprueba el script de agent-browser con el título "Lab: Mundo isométrico".

```ts
import { existsSync, readdirSync, readFileSync } from "node:fs";
import { describe, expect, it } from "vitest";

const ROOT = new URL("../", import.meta.url).pathname;
const claude = readFileSync(`${ROOT}CLAUDE.md`, "utf8");
const factory = readdirSync(`${ROOT}.factory`, { withFileTypes: true })
  .filter((d) => d.isFile())
  .map((d) => [d.name, readFileSync(`${ROOT}.factory/${d.name}`, "utf8")] as const);
const METHOD = "docs/superpowers/specs/2026-10-17-barcos-inventario.md";

describe("notas para agentes: base y URL del lab (#99)", () => {
  it("ni CLAUDE.md ni .factory/ mencionan /map/", () => {
    expect(claude).not.toContain("/map/");
    for (const [f, txt] of factory) expect(txt, f).not.toMatch(/\/map(\/|\b)/);
  });
  it("CLAUDE.md da la base real y abre el lab en /lab/world.html", () => {
    expect(claude).toMatch(/vite\.config\.ts/);
    expect(claude).toContain("/lab/<página>.html");
    expect(claude).toMatch(/open http:\/\/localhost:5173\/lab\/world\.html/);
  });
  it("el comentario de dev_server en config.toml apunta a la raíz y a /lab/", () => {
    const toml = factory.find(([f]) => f === "config.toml")?.[1] ?? "";
    expect(toml).toContain("http://localhost:5173/lab/<page>.html");
  });
});

describe("notas para agentes: advertencia de headless (#99)", () => {
  it("CLAUDE.md advierte fps, deltaMS y el rendimiento de ?speed=", () => {
    expect(claude).toMatch(/~?2 fps/);
    expect(claude).toMatch(/deltaMS/);
    expect(claude).toMatch(/100 ms/);
    expect(claude).toMatch(/0,2·N/);
  });
  it("CLAUDE.md enlaza el método del time-lapse y la sección existe", () => {
    expect(claude).toContain(`(${METHOD}#método-del-time-lapse)`);
    expect(existsSync(`${ROOT}${METHOD}`)).toBe(true);
    expect(readFileSync(`${ROOT}${METHOD}`, "utf8")).toMatch(/^## Método del time-lapse$/m);
  });
});
```

## Assumptions

1. **Commit de tests en rojo.** `test(#99): evals` deja la rama en rojo hasta la Task 2. La etapa 3 del pipeline de factory lo pide así ("Commit the failing tests"). La rama se fusiona con squash, así que `main` nunca ve ese estado. Alternativa descartada: commitear test y doc juntos, que borra el ciclo rojo-verde.
2. **Línea larga del enlace.** La URL del enlace no se corta (Markdown no admite cortar el destino de un enlace). Esa línea pasa de 80 columnas; las demás siguen en ~78. Alternativa descartada: un enlace de referencia `[...][m]` al pie, que agrega otra forma de enlazar que `CLAUDE.md` no usa.
3. **Recorrido de `.factory/`.** Se leen solo archivos regulares (`withFileTypes` + `isFile()`). Hoy hay dos, `config.toml` y `setup.sh`, ambos de texto.
4. **`ROOT` con `.pathname`.** Se sigue el patrón de `src/lab/docs.test.ts:4`. El checkout es `/work`, sin espacios.
