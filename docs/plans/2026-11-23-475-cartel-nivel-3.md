# Hotel sign: level 3, scene captures and docs closing (#475) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Measure the RESUME sign on the hotel facade (#474, cap 12) at level 3. Regenerate the reports and scene captures, and bring every doc that still describes the tower, its crown or its helipad up to date with the hotel.

**Architecture:** This is a docs-and-evidence issue, and no runtime code changes. `npm run legibility` writes the reports and crops. agent-browser takes the scene captures. `src/lab/docs.test.ts` gains a `describe("hotel sign level 3 and docs closing (#475)")` block that pins the new state against the live constants (`SIGN_SITE`, `RESUME_SIGN`) and the generated reports. The docs are then edited until that block and the existing #374/#457 blocks are green.

**Tech Stack:** TypeScript, Vitest, tsx scripts, agent-browser 0.27 (headless Chrome), tesseract.js (inside `npm run legibility`).

**Spec:** issue #475 (body and acceptance criteria), story #471 (plan comment, decisions D9/D10/D15). Related specs: `docs/superpowers/specs/2026-11-22-resume-centro-costero-design.md` §7, `2026-11-18-composicion-responsive-design.md` §8.3, `2026-11-15-carteles-de-zona-rediseno-design.md` §8.1/§8.3/§8.4, `2026-10-17-storybook-estructuras-design.md` (index table).
