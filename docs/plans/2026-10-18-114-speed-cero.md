**Goal:** que `?speed=0` congele el reloj de los animadores del lab y del storybook, en vez de caer a velocidad 1.

## Decisiones técnicas (declaradas)

1. **`?speed=` vacío o solo espacios** cuenta como ausente (→ 1). `Number("")` y `Number(" ")` dan 0, pero un parámetro en blanco no es un 0 explícito, así que no congela: se recorta antes de mirar si está vacío.
2. **`-0`** cuenta como 0 (congela): no es negativo, y se normaliza para que el resultado sea `0` y no `-0`.
3. **Parseo**: se usa `Number(v)`, como hoy. Acepta espacios alrededor y notaciones como `1e-3`; no se endurece más porque el brief no lo pide.
4. **Sin guarda en `stage.tick`**: a los animadores les llega `dtMs = 0`, tal como pide el brief, y el test de integración comprueba que no redibujan nada.

## Assumptions

Decisiones técnicas sin fuente escrita, tomadas en la revisión del plan (etapa 2). Van también en la descripción del PR.

- **A1. Valor en blanco.** `?speed=%20` vale 1, igual que `?speed=`, y no congela. Se descartó dejar que `Number(" ") = 0` congele: el brief pide 1 para "no numérico", y un blanco no es un 0 explícito.
- **A2. Formas numéricas.** Se acepta todo lo que acepta `Number()` (`.5`, `+2`, `1e-3`, `0x10`; `0x0` congela). Se descartó una gramática más estricta: el brief no la pide y hoy el lab ya parsea con `Number()`.
- **A3. El velo también se congela.** `stage.tick` interpola el velo y las luces con `k = min(1, dtMs / LERP_MS)` (`src/world/stage.ts:175`). Con `?speed=0`, la tecla 5 cambia el foco pero el fundido no avanza. Se descartó una guarda que mantenga el reloj del velo, porque el brief pide que "el reloj se congela: los animadores reciben `dtMs = 0`", y el velo vive en ese mismo reloj. El bloom (tecla 6) no depende de `dtMs`, así que se sigue viendo.
- **A4. Ninguna guarda en las páginas.** Con `speed = 0` se sigue llamando a `stage.tick(0)`; no se salta la llamada. Así es literalmente lo que pide el brief, y el test de integración comprueba que no hay redibujos.

```ts
/** `?speed=` escala el reloj de los animadores; 0 lo congela. Ausente, vacío, no numérico, negativo o infinito: 1. */
export function speedFromSearch(search: string): number {
  const v = new URLSearchParams(search).get("speed")?.trim();
  const n = v ? Number(v) : NaN;
  return Number.isFinite(n) && n >= 0 ? n + 0 : 1;
}
```

(`n + 0` convierte `-0` en `0`.)
