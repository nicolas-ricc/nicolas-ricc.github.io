# `?speed=0` congela el reloj del lab (#114): plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** que `?speed=0` congele el reloj de los animadores del lab y del storybook, en vez de caer a velocidad 1.

**Architecture:** un helper puro `speedFromSearch(search)` en `src/lab/page.ts`, junto a `bloomFromSearch`, que las dos páginas usan en lugar de `Number(...) || 1`. El reloj congelado no necesita más cambios: con `dtMs = 0` los animadores ya no devuelven ids para redibujar (sondeado en la etapa 0), y un test de integración sobre `assembleWorld` lo fija.

**Tech Stack:** TypeScript, Vitest, PixiJS v8 (sin cambios), agent-browser.

**Spec:** issue #114 y su Agent Brief (comentario de triage).

## Global Constraints

- Firma: `speedFromSearch(search: string): number`, exportada desde `src/lab/page.ts` junto a `bloomFromSearch`.
- Valores: ausente o no numérico → 1; `0` → 0; positivo finito → el valor; negativo → 1. `Infinity` → 1, porque no es finito.
- Fuera de alcance: velocidades negativas (reproducción hacia atrás).
- `npm test` y `npm run typecheck` en verde.
- Texto en castellano, como el resto de `src/lab/`. Commits `test(#114): …`, `fix(#114): …`.

## Decisiones técnicas (declaradas)

1. **`?speed=` vacío** cuenta como ausente (→ 1). `Number("")` da 0, pero un parámetro vacío no es un 0 explícito, así que no congela.
2. **`-0`** cuenta como 0 (congela): no es negativo, y se normaliza para que el resultado sea `0` y no `-0`.
3. **Parseo**: se usa `Number(v)`, como hoy. Acepta espacios alrededor y notaciones como `1e-3`; no se endurece más porque el brief no lo pide.
4. **Sin guarda en `stage.tick`**: a los animadores les llega `dtMs = 0`, tal como pide el brief, y el test de integración comprueba que no redibujan nada.

## Review Focus

1. `?speed=` vacío o `?speed` sin valor no debe congelar: se espera 1 (test en Task 1).
2. `?speed=-0` congela y devuelve `0`, no `-0` (test en Task 1).
3. `?speed=1e-3` y `?speed=%202%20` (con espacios) se aceptan como números: 0.001 y 2 (test en Task 1).
4. Que otro parámetro venga antes (`?bloom=off&speed=0`) no cambia nada: congela (test en Task 1).
5. Con `reducedMotion` encendido, el reloj congelado tampoco redibuja (test en Task 2).

```ts
/** `?speed=` escala el reloj de los animadores; 0 lo congela. Ausente, vacío, no numérico, negativo o infinito: 1. */
export function speedFromSearch(search: string): number {
  const v = new URLSearchParams(search).get("speed");
  const n = v ? Number(v) : NaN;
  return Number.isFinite(n) && n >= 0 ? n + 0 : 1;
}
```

(`n + 0` convierte `-0` en `0`.)
