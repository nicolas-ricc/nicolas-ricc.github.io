# Writing: apply #451's size decision — `WRITING_CAP` 17.25 and ground-sign floors (#460) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** WRITING on the plank raft drops from cap 20 to the owner's 17.25, and the legibility oracle gets its own floors for ground signs, so level 2 and the ships rule stay green over every pose of the cycle at both sites.

**Architecture:** `SIGN_RULES` (`src/kit/legibility.ts`) gains a `ground` entry keyed by cover scale; `checkSign` reads it instead of the per-scale entry when `spec.ground` is true, and only for x-height, stroke, air and contrast (the projection limits, backing and occlusion stay shared). `WRITING_CAP` (`src/scenes/raft.ts`, re-exported by `sign-platform.ts`) becomes 17.25; the sheet, planks, beams, foam and shadow already derive from the ink box. Tests that pin 20 or the measured values are re-pinned, and the 2026-11-15 spec's #451 entry plus `CONTEXT.md` record the decision, the floors and the values measured at 17.25 for #457.

**Tech Stack:** TypeScript, Vitest (node, no Pixi); `npm run legibility` (agent-browser + tesseract.js) for the level-3 pre-check.

**Spec:** issue #460 (its "Qué hacer" and "Aceptación" are binding); story #451 §3 (owner decision 2026-11-20) and the plan comment's D1 (`bar` measured along v).

## Technical decisions (declared; not in the issue)

1. **The stroke is measured as the oracle already does (D1 of #451): min(`stroke` along u, `bar` along v).** The issue's "≈ 1.71 / 1.21 px" applies the 0.12 stem face along v. The oracle measures the real bar thickness along v (`CHAINSAW_BAR` 0.15), which gives 2.14 / 1.52 px at rest. The issue's column header says "the one the ground class measures: `bar`/`stroke`", so the measure stays. Both values clear 1.6 / 1.2.
2. **Shape of the entry:** `SIGN_RULES.ground = { [COVER_LAPTOP]: {...}, [COVER_PHONE]: {...} }`, same keys as the per-scale entries. `checkSign` picks `S = spec.ground ? R.ground[scale] : R[scale]`. Contrast ≥ 7 is a ground floor, so it applies to any ground sign, not only to decals.
3. **REPORT.md is not rewritten here.** It belongs to #457, which replaces level 3 for ground signs (`--tick`, symmetric halo). The pre-check runs `npm run legibility -- --only <id>` for the two Writing contexts. Its OCR readings go into the issue comment, the PR and the #451 entry. The generated `REPORT.md` and crops are restored with `git checkout`.
4. **Captures are not regenerated.** The issue does not ask for them, and #457 owns the "capturas finales". The cap-20 PNGs stay until then.
5. **The record for #457 is the #451 entry of §8.2** in `docs/superpowers/specs/2026-11-15-carteles-de-zona-rediseno-design.md`, plus §8.1, §8.3 and `CONTEXT.md`. ADR 0005 is #457's.
