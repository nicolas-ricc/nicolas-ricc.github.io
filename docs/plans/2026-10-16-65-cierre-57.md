## Assumptions

- **Majority rule for isolated spikes.** The issue asks for two warm runs; the mundo-3 spec ("Desvíos", Task 9) already ran a third run and decided by majority when one reading was an isolated spike. Same rule here; the test requires `SHIP_STEP_MS = 66` when half or more of the readings exceed 15 ms. Rejected: activating `SHIP_STEP_MS` on any single reading > 15 ms (would react to shared-machine noise the spec already discounts).
- **`SHIP_STEP_MS` throttles the redraw, not the clock.** The issue says "los barcos se redibujan cada 66 ms en vez de cada tick"; ship state keeps advancing every tick so phases `k·T/3` and the ferry stay untouched. Rejected: quantising the ships' clock to 66 ms steps.
- **DPR.** If `agent-browser` cannot force `deviceScaleFactor` 2, the measurement records the DPR actually used and says so in the section.
- **README wording.** The test checks the concepts the issue names ("fondeadero de la bocana", "dos carriles", "abajo-izquierda"), not constant names. Rejected: requiring `LANE_OUT` / `LANE_BACK` in the README.
