# Accent layers out of the bloom: `bloom: false` on `AnimLayer` (#443) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An animated accent layer can declare `bloom: false`. It is still drawn additively in `accentSlot`, but the lazy `bloomSlot` gets no blurred mirror of it, so the paint on the Writing board reads as paint, not neon.

**Architecture:** The `kind: "accent"` branch of `AnimLayer` (`src/scenes/animator.ts`) gets an optional literal field `bloom?: false`. `buildStage` (`src/world/stage.ts`) reads it once per layer at construction, the same way it reads `zone`, and stores it on each `AccentGraphics` entry. `buildBloomSlot` skips the entries that are out of the bloom. `applyAlphas` already tolerates `e.mirror === undefined`. The halo, the veil, `setLayer` and `destroy` don't change.

**Tech Stack:** TypeScript, Vitest (node; `stage.test.ts` is one of the two Pixi tests, with stubbed filters), PixiJS v8.

**Spec:** issue #443 ("Decisiones tomadas" and "Criterios de aceptación" are binding); story #441, plan comment, decision 4.

## Global Constraints

- The field is exactly `bloom?: false`: only that literal. Without it the layer is in the bloom, as today.
- Docstring in `animator.ts`, verbatim: «`bloom: false`: the layer is drawn additively like every light but gets no mirror in the bloom slot (paint, not neon)».
- `AccentGraphics` stores whether its layer has `bloom === false`. It is read from `a.layer(id)` at construction, like `zone`, and is not re-read on later redraws.
- `buildBloomSlot` creates no mirror for those entries (`e.mirror` stays `undefined`). The halo (`fallback`), the veil, `setLayer` and `destroy` don't change.
- `README.md`, in the bloom paragraph («The lights' bloom is not part of the first draw…»): one sentence saying that an accent layer declared `bloom: false` stays out of the bloom (drawn additively, with no blurred mirror), and that the paint of the Writing board is that case.
- No new file imports Pixi outside `PIXI_TESTS` (`src/iso/pixi-free.test.ts`).
- Code, comments and test names are in English (`src/english.test.ts`).
- `npm test` and `npm run typecheck` are green.

## Technical decisions (declared; not in the issue)

1. **Static accents are always in the bloom.** They have no `AnimLayer`, so their entries get `bloom: true`.
2. **The mirror ↔ original order is kept.** The mirrors are added in `accents` order, skipping the excluded entries. The tests therefore compare the mirrors index by index with the `accentSlot` children *filtered by the rule*, not with all of them.
3. **The flag is fixed at construction.** A layer that changes `bloom` between redraws keeps the value it had at build time, like `zone`. Nothing in the world does that.
4. **The rule lives in the test as a helper.** `bloomFlags(animators)` gives one boolean per `accentSlot` child, in build order: the `WORLD_ZONES.length` static entries are `true`; then, for each animator and each id whose layer is `kind: "accent"`, 1 entry (if it declares `zone`) or `WORLD_ZONES.length` entries, each equal to `layer.bloom !== false`. The existing mirror tests (count and alpha) use it, so they keep holding once #444 marks `platform.lights`.

## Review Focus

- A `bloom: false` layer with a declared `zone` (a single Graphics) → no mirror either. Test in Task 1 (`zone: "blog", bloom: false` → only the static mirrors).
- A focus change with a `bloom: false` layer present → the remaining mirrors copy the alpha of *their* original (no shift by index), and the excluded Graphics still dims with the veil. Test in Task 1.
- `fallback` with a `bloom: false` layer → the layer is still redrawn with the large halo (the halo is not the bloom). Covered by the unchanged redraw path; asserted in Task 1 (`fills` grows for that layer's Graphics).
- `on → fallback → on` and `destroy` with the layer present → no exception, one `bloomSlot`, blur filter freed, the excluded Graphics and its context destroyed by the tree. Test in Task 1.
- The real world today (no layer declares `bloom: false`) → mirror count = total `accentSlot` children. Covered by the rule-based existing test.
