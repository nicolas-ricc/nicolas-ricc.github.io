## Decisiones técnicas (supuestos declarados)

Medidas tomadas sobre la rama base (`f467450`) con un prototipo descartable, semilla del mundo (`zoneRng(7, "cv")`, `zoneRng(7, "cv", 1)`), 990 sólidos y 1695 ventanas publicadas.

1. **Oclusión = `overlaps(screenBounds) && isBehind && siluetas que se cruzan`.** Con solo `overlaps(screenBounds) && isBehind` (letra del issue) la regla apaga 1328 de 1695 ventanas y declara ocluidos los 8 slots de neón abiertos de la semilla del mundo: las cajas de pantalla de la torre de la plaza (30 de alto) o de un techo con vuelo cubren rincones vacíos de su silueta. La silueta exacta de una caja 3D proyectada es el casco convexo de sus 8 esquinas (un hexágono); sigue siendo conservadora respecto del sólido real (el sólido está dentro de su caja), y con ella quedan ocluidas 499 ventanas. Se agrega a `src/iso/depth.ts` `screenHull(b)` y `hides(back, front)`; el oráculo del test usa el mismo predicado por fuerza bruta. El AABB de pantalla queda como prefiltro barato.
2. **Neones también pasan por la oclusión.** El issue dice que no hace falta porque están en frentes abiertos, pero en la semilla del mundo los 5 slots del frente sur de `(102, 188)` (sobre la avenida) quedan detrás de la torre de la plaza (`x 121..137`, `y 220..234`, 30 de alto) y de dos postes de farol de la vereda: el oráculo los marca. Manda el criterio de aceptación ("ningún neón delante de un sólido que debería taparlo"), así que se filtran con `hides` contra **todos** los sólidos (un slot no tiene edificio propio; su propia pared no lo tapa: comprobado). Consecuencia: en la semilla del mundo quedan **3** neones (frente este de `(162, 164)` sobre la calle del muelle), no ≥ 8; el test exige ≥ 3 en esa semilla. La falta de frentes abiertos con slots en el barrio de bares va a #165.
3. **"On con probabilidad `lights.on`" = cupo exacto por barrio.** Con tiradas Bernoulli independientes la ribera de la semilla del mundo da 14/84 = 16.7 % contra 25 % (fuera de ±8). Se tira una clave `rng.next()` por candidata en el orden de recorrido (por `placed`, por ventana), y en cada barrio, ordenadas por clave, las primeras `round(on·n)` se encienden y de ellas las primeras `round(warm·nOn)` son cálidas. Cada ventana tiene probabilidad marginal `on` (y `warm` dada encendida), determinista, y los porcentajes caen a ±1 ventana del objetivo.
4. **Z del neón relativa al lote.** `neonSlot` en `src/kit/forms/lowrise.ts` documenta "z `lot.z + 2.4 .. + 3.6`" y la semilla del mundo los publica en 2.7..3.9 con `lot.z = 0.3`. Se valida `2.4 ≤ p.z − lot.z ≤ 3.6` (con 1e-6).
5. **`counts[barrio].candidates`** cuenta candidatas **no ocluidas** (sobre las que se mide el porcentaje). Barrios sin piezas quedan en cero.
6. **Orden de consumo del rng:** claves de ventanas → animables → elección de neones si hay > 24 → color de cada neón en orden de recorrido. Las animables: muestra uniforme sin reemplazo de 40 (o todas si hay menos) entre las candidatas del centro y el residencial.
7. **Charco del neón:** centro del slot desplazado 1 por `slot.wall` en planta, `z = lot.z`, `puddle(x, y, `${color}Bleed`, lot.z)` (tres octógonos alpha 0.25).
8. **Banda bañada:** `[pts[0], pts[1], pts[1] + floorH, pts[0] + floorH]` de la `Wall` (base en `pts[0..1]`, ver `addBuilding` en `src/kit/piece.ts`), corrida 0.05 por `normal`. Sin oclusión (el issue no la pide).
9. **Guirnaldas en las terrazas del muelle** (spec §7) quedan fuera: las terrazas son de #48.
10. **Oráculo con caché propia:** recorrer todos los sólidos por cada ventana encendida, sin barrido; el test calcula `bounds` de cada sólido una vez por su cuenta (teselar 990 sólidos × ~600 ventanas por par sería lento) y no reutiliza nada de `lights.ts`.

## Review Focus

- Una ventana tapada por un ala o cornisa de su **misma** pieza (no solo por el edificio de enfrente) tiene que apagarse → el oráculo recorre todos los sólidos salvo `solids[solidOffset + building]` (Task 2).
- El barrido no puede perder pares: un sólido muy ancho que empieza muy a la izquierda de la ventana igual la tapa → test con un sólido largo a la izquierda (Task 1/2).
- Determinismo: mismo rng → mismo `JSON.stringify`; y cambiar `lightsRng` no cambia `solids` (las luces no consumen el rng de la ciudad) → Task 4.
- Barrio sin candidatas (p. ej. cívico tapado entero) no divide por cero ni rompe `counts` → Task 2.
- Un slot de neón fuera de 2.4..3.6 sobre el lote se descarta en vez de pintar un neón flotando → Task 3.

```ts
/** Silueta en pantalla de una caja: casco convexo de sus 8 esquinas proyectadas (monotone chain). */
export function screenHull(b: Bounds): Vec2[] {
  const ps: Vec2[] = [];
  for (const x of [b.min.x, b.max.x]) for (const y of [b.min.y, b.max.y]) for (const z of [b.min.z, b.max.z]) ps.push(project(v3(x, y, z)));
  ps.sort((p, q) => p.x - q.x || p.y - q.y);
  const cross = (o: Vec2, a: Vec2, c: Vec2): number => (a.x - o.x) * (c.y - o.y) - (a.y - o.y) * (c.x - o.x);
  const half = (pts: Vec2[]): Vec2[] => {
    const out: Vec2[] = [];
    for (const p of pts) { while (out.length >= 2 && cross(out[out.length - 2]!, out[out.length - 1]!, p) <= EPS) out.pop(); out.push(p); }
    return out.slice(0, -1);
  };
  return [...half(ps), ...half([...ps].reverse())];
}

/** Dos polígonos convexos se cruzan si ningún eje de sus bordes los separa (tocarse no cuenta). */
export function hullsOverlap(a: Vec2[], b: Vec2[]): boolean {
  for (const poly of [a, b]) for (let i = 0; i < poly.length; i++) {
    const p = poly[i]!, q = poly[(i + 1) % poly.length]!, nx = q.y - p.y, ny = p.x - q.x;
    let aMin = Infinity, aMax = -Infinity, bMin = Infinity, bMax = -Infinity;
    for (const v of a) { const d = v.x * nx + v.y * ny; aMin = Math.min(aMin, d); aMax = Math.max(aMax, d); }
    for (const v of b) { const d = v.x * nx + v.y * ny; bMin = Math.min(bMin, d); bMax = Math.max(bMax, d); }
    if (aMax <= bMin + EPS || bMax <= aMin + EPS) return false;
  }
  return true;
}

/** `front` tapa a `back`: `back` queda detrás y sus siluetas se cruzan en pantalla. */
export function hides(back: Bounds, front: Bounds, hulls?: { back: Vec2[]; front: Vec2[] }): boolean {
  return isBehind(back, front) && hullsOverlap(hulls?.back ?? screenHull(back), hulls?.front ?? screenHull(front));
}
```
