# Lab world help lists `?speed=` and `?bloom=` (#180) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** the runtime help of `lab/world.html` (the `aria-label` of `#lab-host`) documents the URL parameters `?bloom=` and `?speed=` (with `?speed=0` freezing the clock), pinned by `src/lab/page.test.ts`.

**Architecture:** static copy appended to one HTML attribute. No script changes: `bloomFromSearch` / `speedFromSearch` (`src/lab/page.ts:16-30`) already implement what the copy describes. The test reads `lab/world.html` as text, like the existing "Tecla 6" case (`src/lab/page.test.ts:35-38`), and ties the "hasta 100" number to `MAX_SPEED` so the copy cannot drift from the cap.

**Tech Stack:** static HTML, TypeScript strict, Vitest (`environment: "node"`).

**Spec:** issue #180 and the owner's decision comment of 2026-11-01: "La ayuda (`aria-label`) de `lab/world.html` lista `?speed=` (0 congela el reloj) y `?bloom=`, fijado en `src/lab/page.test.ts`. Las otras páginas del lab quedan como están."

## Global Constraints

- Only `lab/world.html` changes among the lab pages; `blog`, `resume`, `portfolio` and `storybook` HTML stay byte-identical.
- The `aria-label` copy is visitor/screen-reader text and stays in Spanish, like the rest of the label; it is not translated (#194 excludes visitor copy). New test names are in English (#194, as in #167).
- The existing label text stays as is, including "Teclas 0..3" (the missing key 4 is #302, not this issue). The new sentences are appended at the end.
- The existing test "la ayuda de teclas sigue describiendo la tecla 6" keeps passing untouched; so do `src/lab/host.test.ts` and `src/lab/host-keyboard.test.ts`.
- Commits `<type>(#180): ...`. `npm test` and `npm run typecheck` green.
- Pipeline evals stage: Task 1 Step 1 (the failing test) is committed alone as `test(#180): evals` before implementation; implementers start at Task 1 Step 3.

## Technical decisions (declared)

1. **Exact copy appended** to the world `aria-label`, after "Tecla 6 rota el bloom: off, on, fallback.":

   ` ?bloom=on|off|fallback lo fuerza al cargar. ?speed= escala el reloj de las animaciones hasta 100; ?speed=0 lo congela.`

   Wording follows the `bootWorldPage` docstring (`src/lab/page.ts:39-41`: "`?bloom=on|off|fallback` lo fuerza al cargar", "`?speed=` escala el reloj … (hasta 100) y `?speed=0` lo congela") and README (`README.md:98-100`: "`?speed=` escala el reloj de las animaciones hasta 100 (`?speed=0` lo congela"). "Lo" in the bloom sentence refers to the bloom of the previous sentence.
2. **Number tied to the constant:** the test builds the expected `?speed=` sentence with `MAX_SPEED` imported from `./page`, so raising the cap without updating the copy fails the suite.
3. **No `aria-keyshortcuts` change:** URL parameters are not keys.

## Review Focus

1. The copy says something the code does not do (e.g. a cap other than `MAX_SPEED`, a bloom value `bloomFromSearch` ignores) — the test uses `MAX_SPEED` and the exact `on|off|fallback` list, the three values of `BLOOM_CYCLE`.
2. A `"` or unescaped character breaking the attribute and truncating the label — the test regex matches inside `aria-label="[^"]*…"`, and `src/lab/host.test.ts` still finds the attribute.
3. The other lab pages edited by accident — test asserts none of `blog`, `resume`, `portfolio`, `storybook` HTML mentions `?speed=`.
4. The existing key help lost while editing — the "Tecla 6" test stays green.
5. The label as actually exposed in the browser differs from the source (e.g. a build step rewriting it) — browser script `.scratch/evals-180.md` reads `#lab-host`'s `aria-label` on the dev server.

- [ ] **Step 1: Write the failing test** in `src/lab/page.test.ts`:

```ts
describe("lab world help documents URL parameters (#180)", () => {
  const label = /aria-label="([^"]*)"/.exec(readFileSync(`${ROOT}lab/world.html`, "utf8"))?.[1] ?? "";
  it("lists ?bloom= with the modes it forces", () => {
    expect(label).toContain("?bloom=on|off|fallback lo fuerza al cargar.");
  });
  it("lists ?speed= with its cap and ?speed=0 freezing the clock", () => {
    expect(label).toContain(`?speed= escala el reloj de las animaciones hasta ${MAX_SPEED}; ?speed=0 lo congela.`);
  });
  it("leaves the other lab pages' help alone", () => {
    for (const p of ["blog", "resume", "portfolio", "storybook"]) {
      expect(readFileSync(`${ROOT}lab/${p}.html`, "utf8"), p).not.toContain("?speed=");
    }
  });
});
```
